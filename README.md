# Вариант №17 — этап 1 (REPL)

GUI-прототип эмулятора командной оболочки ОС по практической работе
«Конфигурационное управление».

## Требования варианта №17

По этапу 1 реализованы все требования варианта №17:

1. Приложение реализовано в форме графического интерфейса (GUI).
2. Заголовок окна содержит имя VFS: `VFS-17`.
3. Парсер раскрывает переменные окружения реальной ОС, например `$HOME`.
4. Команды-заглушки `ls` и `cd` выводят имя команды и переданные аргументы.
5. Реализована команда `exit`.
6. Подготовлены интерактивные примеры работы всех функций, включая ошибки.
7. Результат этапа сохранён в Git-коммите с Conventional Commit.

Обработка ошибок нужна для демонстрации интерактивной работы: неизвестная
команда, неверные аргументы `exit` и ошибка разбора команды отображаются в GUI.

## Реализованные функции и настройки

- `expand_variables()` — раскрывает переменные окружения через `os.path.expandvars`.
- `parse_command()` — раскрывает переменные и разбирает командную строку.
- `execute_command()` — выполняет команды этапа 1 и возвращает результат.
- `ls` — заглушка, выводит `ls` и аргументы.
- `cd` — заглушка, выводит `cd` и аргументы.
- `exit` — завершает работу эмулятора; аргументы запрещены.
- Заголовок: `Эмулятор оболочки — VFS-17`.
- Prompt формируется из имени пользователя и hostname реальной ОС.
- Интерфейс использует Tkinter; отдельный диалог `messagebox` показывает ошибки.

## Структура репозитория


## Требования к окружению

Python 3.10+ и Tkinter. Дополнительные сторонние Python-пакеты не требуются.

## Запуск

Linux/macOS:

```bash
./run.sh
```

или:

```bash
make run
```

Windows:

```bat
run.bat
```

или:

```bat
py src\main.py
```

## Запуск тестов

Linux/macOS:

```bash
make test
```

Windows:

```bat
py -m unittest discover -s tests -v
```

## Примеры интерактивной работы

В окне эмулятора:

```text
username@hostname:VFS-17$ ls -la
ls -la
username@hostname:VFS-17$ cd "$HOME"
cd /home/username
username@hostname:VFS-17$ unknown
Ошибка: Неизвестная команда: unknown
username@hostname:VFS-17$ exit now
Ошибка: Команда exit не принимает аргументы
username@hostname:VFS-17$ exit
Выход из эмулятора.
```

Значения `username`, `hostname` и `$HOME` берутся из реальной ОС при запуске.
